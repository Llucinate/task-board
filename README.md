# 📌 Доска задач

Общая доска со стикерами-задачами: любой может повесить задачу, взять её в работу или снять.

## Структура
- `index.html` — сайт (адаптивный: компьютер и телефон)
- `api/notes.js` — серверная функция Vercel (GET / POST / PATCH / DELETE)
- Данные хранятся в Upstash Redis (подключается в Vercel в пару кликов, бесплатный тариф)

## Деплой
1. Залить папку в репозиторий на GitHub.
2. vercel.com → Add New → Project → выбрать репозиторий → Deploy (настройки не трогать).
3. В проекте: вкладка **Storage** → Create / Marketplace → **Upstash for Redis** → Free → Connect к проекту.
4. Deployments → у последнего деплоя ⋯ → **Redeploy** (чтобы подхватились ключи базы).

Без базы сайт тоже откроется, но задачи будут теряться — так что шаг 3 обязателен.
