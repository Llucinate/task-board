# Доска задач

Общая доска с компактными стикерами. На доске видны только заголовки, подробности открываются нажатием на карточку.

## Возможности

- Создание и редактирование названия, описания, категории и цвета заметки.
- Создание категорий и фильтрация по категории и статусу.
- Подзадачи внутри цели: добавление, редактирование, выполнение и удаление, счётчик прогресса.
- Вкладка «Настройки»: имя профиля автоматически подписывает новые заметки и взятые задачи.
- Имя хранится только в текущем браузере. Это не аккаунт и не разграничение прав: доска общая, любой посетитель может менять задачи.
- Проверка версии заметки при редактировании и защита от потери параллельных правок.

## Устройство

- `index.html`, `styles.css`, `app.js`: адаптивный интерфейс без сборки.
- `api/notes.js`: Vercel Function, GET / POST / PATCH / DELETE.
- `api/notes?resource=categories`: получение и создание категорий через ту же функцию.
- `api/_lib/`: серверное хранилище и обработчик категорий.
- `tests/api.test.js`: проверки API. Запуск: `npm install`, затем `npm test`.

## Хранилище

Для постоянного общего хранения подключите Upstash Redis к проекту Vercel и задайте серверные переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` (также поддерживаются `KV_REST_API_URL` и `KV_REST_API_TOKEN`). После изменения переменных нужен новый деплой.

**Без Redis задачи и категории хранятся в памяти экземпляра функции: могут исчезать при перезапуске, новом деплое и отличаться между экземплярами. Интерфейс показывает предупреждение.** Имя профиля сохраняется отдельно в браузере.

В GitHub и статические файлы секреты не добавлять. `.env*`, `.vercel`, `node_modules` исключены через `.gitignore`.
